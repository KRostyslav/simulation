# @edu/diode

Фізика напівпровідникового діода, спільна для всіх симуляцій монорепи.

Пакет не знає ні про DOM, ні про канву, ні про конкретну лабораторну роботу.
Він відповідає на одне питання: **який струм потече при такій напрузі, такій
температурі й такому легуванні**.

## Що всередині

| Модуль | Про що |
| --- | --- |
| `constants.js` | параметри кремнію та германію одним набором полів, геометрія зразка |
| `intrinsic.js` | `n_i(T)`, ширина забороненої зони за Варшні, тепловий потенціал |
| `transport.js` | рухливість за Кохі–Томасом, дифузія, провідність |
| `doping.js` | рівноважні концентрації, час життя носіїв |
| `junction.js` | збіднений шар, контактна різниця потенціалів, ємність переходу |
| `generation.js` | генерація в збідненому шарі — другий механізм струму |
| `breakdown.js` | напруга пробою, тунельний і лавинний механізми |
| `diode.js` | формула Шоклі, послідовний опір, розв'язувач робочої точки |

## Матеріал як параметр, а не як гілка

Кожна функція приймає матеріал останнім параметром із дефолтом `SI`:

```js
intrinsicConcentration(300)      // 1,0·10¹⁰ см⁻³ — кремній
intrinsicConcentration(300, GE)  // 2,4·10¹³ см⁻³ — германій
```

Різниця між кремнієм і германієм — це різниця в семи числах, а не в семи `if`.
Уся поведінка германієвого діода (поріг 0,3 В, великий зворотний струм, рання
втрата випрямних властивостей при нагріванні) випливає з одного факту:
заборонена зона вдвічі вужча.

## Три механізми, і два з них вимкнені за замовчуванням

`solveDiodeCurrent` рахує ідеальну модель Шоклі з послідовним опором. Генерація
в збідненому шарі (`igen`) і зворотний пробій (`breakdown`) вмикаються явно.

Це не оптимізація, а вимога до навчального застосунку: увімкнений механізм
змінює числа, а не уточнює їх, і мовчки міняти під учнем те, що він щойно
виміряв, не можна. Тому вимкнені механізми стоять під `if`, а не помножені на
нуль, і `regression.test.js` фіксує точні double-значення дефолтного шляху.

## Контрольні числа

| Величина | Si | Ge |
| --- | --- | --- |
| `E_g(300)` | 1,12 еВ | 0,66 еВ |
| `n_i(300)` | 1,0·10¹⁰ см⁻³ | 2,4·10¹³ см⁻³ |
| `U` при 1 мА | 0,68 В | 0,29 В |
| `dU/dT` | −1,9 мВ/К | −1,8 мВ/К |
| Зворотний струм на +10 К | ×2,2 | ×2,6 |
| `U_проб` при 10¹⁶ см⁻³ | 62 В | 28 В |

Кремній при легуванні 2,4·10¹⁷ см⁻³ дає пробій 5,7 В із майже нульовим
температурним коефіцієнтом — тобто звичайний стабілітрон.

```bash
cd packages/diode && node --test
```

Тести не мають зовнішніх залежностей і запускаються без `pnpm install`.
