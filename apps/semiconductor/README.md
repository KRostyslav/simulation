# Лабораторія напівпровідників

Піксельна гра-пісочниця для трьох тем шкільного курсу фізики:
**напівпровідники**, **власна і домішкова провідність**, **p-n перехід**.

Гравець крутить регулятори — температура, домішка та її концентрація,
освітлення, напруга — і бачить, що відбувається всередині кристала. Після
кожної дії застосунок пояснює, ЯК саме ця дія подіяла і чому.

```bash
pnpm dev --filter @edu/semiconductor
```

## Як це вчить

**Живий коментар під сценою** — головна фіча, а не додаток. Після кожної зміни
регулятора він каже, що сталося і за яким механізмом, підставляючи реальні
числа з розрахунку.

**Три рівні пояснення** (перемикач у шапці):

1. тільки числа;
2. + механізм словами («кожен атом фосфору віддає ґратці п'ятий електрон,
   якому не потрібно рвати зв'язок»);
3. + формула символьно й із підставленими числами.

**Підказки на межах моделі.** Коли наближення перестає працювати, застосунок
каже це вголос, а не показує гарне неправильне число: виродження вище 10¹⁸ см⁻³,
порушення закону діючих мас при освітленні, вичерпання наближення збідненого
шару біля V_bi.

**Довідник** із 15 статей, згрупованих за темами програми, з перехресними
посиланнями — включно з окремою статтею «Що ця модель спрощує».

**Шість завдань**, які нічого не блокують: вони лише дають привід зробити
конкретний експеримент, після якого відкривається теорія.

## Що видно на сцені

- Ґратка кремнію з ковалентними зв'язками; розірвані зв'язки — це теплові пари.
- Домішкові атоми з нерухомими іонами ⊕ / ⊖.
- Вільні носії: електрон — залитий диск, дірка — кільце (порожній зв'язок).
- **Парність:** генерація завжди народжує пару, рекомбінація завжди знищує
  пару, домішка дає непарний носій разом із нерухомим іоном. Тому на екрані
  завжди виконується (електрони − дірки) = (іони ⊕ − іони ⊖) — електронейтральність
  видно очима.
- **Логарифмічна драбина** внизу: мітки n, p, nᵢ і концентрації домішки.
  Закон діючих мас на ній стає видимим — nᵢ завжди рівно посередині між n і p.
- У режимі p-n: збіднений шар без рухомих носіїв, ряди нескомпенсованих іонів,
  внутрішнє поле, профіль бар'єру знизу.
- Графіки: `lg σ` від `1000/T` (для контрасту домальовано мідь) і ВАХ діода
  з тумблером логарифмічної шкали, де експонента стає прямою 60 мВ/декада.

Шкала кількості частинок логарифмічна: концентрації в цій темі різняться на
десять порядків, і лінійно показати 10⁴ та 10¹⁶ разом фізично неможливо.

## Фізична модель

Уся фізика — в [src/physics/](src/physics/), окремо від UI й під тестами.

| Модуль | Що рахує |
| --- | --- |
| `intrinsic.js` | `Eg(T)` за Варшні, `n_i(T)`, `V_T`, температура переходу до власної провідності |
| `doping.js` | `n` і `p` із нейтральності та закону діючих мас, режим провідності, час життя носіїв |
| `transport.js` | рухливість за Кохі–Томасом, `σ`, `ρ`, `R`, дрейф із насиченням, дифузія |
| `optical.js` | генерація від світла, `Δn = G·τ`, дифузійна довжина |
| `junction.js` | `V_bi`, ширина збідненого шару, `x_n`/`x_p`, максимальне поле, ємність |
| `diode.js` | `I_s`, послідовний опір, неявне рівняння Шоклі, ВАХ |
| `model.js` | збірка знімка: значення → показники з поясненнями |

Контрольні точки збігаються з підручником: власний кремній ρ = 3,4·10⁵ Ом·см,
10¹⁶ фосфору — 0,50 Ом·см, 10¹⁶ бору — 1,43 Ом·см, `V_bi` = 0,71 В,
ширина шару 0,43 мкм, нахил ВАХ 60 мВ на декаду.

### Три місця, де легко зробити непомітну помилку

**Неосновні носії рахуються тільки як `n_i²/основні`.** Через різницю
`n − N_net` при `N_d = 10¹⁹` шукана `p ≈ 6,4` становить 10⁻¹⁸ від `n` — у float64
різниця дає рівно нуль, і панель показала б «дірок немає».

**`Math.expm1`, а не `exp(x) − 1`.** При U = 1 мВ друге втрачає всі значущі
цифри, і вся область малих напруг перетворилася б на «струму немає».

**Рівняння Шоклі розв'язується бісекцією разом із послідовним опором.**
Без `R_s` модель при 1 В і 150 К видала б струм 10¹⁹ А; метод Ньютона тут
розбігається, бо похідна експоненти на кінцях відрізка різниться на порядки.

## Тести

```bash
node --test          # 79 тестів, зовнішніх залежностей не потрібно
```

Крім фізики перевіряються дві речі, які легко зламати непомітно:

- **свіп сітки** з понад 1200 станів — жоден показник не дає NaN, нескінченності
  чи від'ємної концентрації;
- **цілісність навчальних даних** — кожне правило коментаря посилається на
  наявний показник і наявну статтю довідника, кожне перехресне посилання
  резолвиться, кожна ціль досяжна.

Рендер тестується строгим контекстом канви, який падає на першій нескінченній
координаті: `undefined` у знімку тихо перетворюється на NaN, браузер малює
порожнечу без жодного попередження, а лінія за Брезенхемом із NaN взагалі
не завершується й вішає вкладку.

## Межі моделі

Одновимірність і різкий перехід; повна іонізація домішки (виморожування при
низьких температурах не показано); одна домішка за раз (без компенсації);
статистика Больцмана (вище 10¹⁸ см⁻³ — лише порядок величини); ідеальний діод
`m = 1` без рекомбінації в збідненому шарі; пробою немає.

Усе це перелічено й у самому застосунку — стаття довідника «Що ця модель
спрощує».
